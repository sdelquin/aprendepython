# Pruebas de software

Las pruebas de software son un conjunto de actividades destinadas a comprobar que una aplicación funciona correctamente y cumple los requisitos establecidos. Mediante las pruebas se pueden detectar errores, verificar el comportamiento del programa y garantizar su calidad antes y después de su puesta en funcionamiento. Estas pruebas pueden realizarse en diferentes niveles y de forma manual o automatizada.
